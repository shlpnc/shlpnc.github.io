# P&C Project Deliverables Dashboard

The Planning & Coordination department at Shanta Holdings Limited uses this internal dashboard to track project deliverables across its portfolio.

**Access is limited to authorised staff.** The dashboard opens on a sign-in page, and its data is encrypted. It cannot be read without a valid user ID and password.

## Opening the dashboard

Open this repository's GitHub Pages address, or the dashboard on the P&C SharePoint page. Sign in with the user ID and password issued by P&C Admin.

## What it shows

- Task status across projects and resources: completed on time, completed late, overdue and upcoming
- Delivery performance against plan, upcoming workload and the schedule
- A searchable tracker with the details of each task

The data is updated periodically. The date it reflects is shown at the top of the dashboard as "Data as of".

## Help

- Forgotten password, or need access? Contact P&C Admin.
- To change your password, sign in and select **Change password** in the menu.
- For how to use the dashboard, see the User Guide shared by P&C Admin.

## Browser support

Current versions of Chrome, Edge, Firefox and Safari.
